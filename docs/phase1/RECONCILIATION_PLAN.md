# RECONCILIATION_PLAN.md — Cognition Phase 1

Goal: prove, with arithmetic, that no valid source material was lost and nothing
unverified was emitted. For every module and unit type:

```
discovered = verified + quarantined + duplicates + irrelevant
```

## 1. What "discovered" means per module (enumeration authority)

| Module | Discovered = | Authority |
|---|---|---|
| Listening tests | 197 pages (+10 slug variants) ↔ listening hub (207 links, incl. exceptions) | hub table + SOURCE_MANIFEST |
| Academic reading | 317 pages (+1 dup) ↔ reading hub (319 links) | hub table |
| GT reading | 125 pages (+1) ↔ GT hub (126 links) | hub table |
| Academic writing | 131 pages ↔ writing hub (132 links) | hub table |
| MCQ drills | 52 ↔ MCQ hub (52) | hub links |
| Speaking cards | 179 pages ↔ makkar hub (180 links) | hub links (delta = 1 dup slug, reconcile) |
| Cambridge identity | 21 book pages → B.T → slug triples | book hubs (partial coverage, advisory identity) |

Deltas between hub link counts and page counts are **itemized**, not absorbed:
slug exceptions (`ielts-listening-6`…), the loose test-111 files, renamed twins
(`listening-15` etc.), `reading-test-105-2`.

## 2. Question-count reconciliation (three independent counts)

Per test: `Σ group ranges` (from structure) vs `blank anchors` ((N)-tokens + fname inputs)
vs `answer-key items`. Report per module: distributions, agreement rate, and the list of
tests where any two disagree (each such test ⇒ targeted quarantine).

Baseline expectations from forensics (strict scan undercounts groups; extraction should
approach 100% agreement):
- listening: 135/197 currently agree on max=40; 8 pages legitimately end at 39;
  1 has no audio; 1 has foreign audio.
- reading: 89/317 currently agree on max=40 (strict scan); all keys sequential.
- GT: 124/125 sequential keys.

## 3. Asset reconciliation

`referenced assets = resolved (content-addressed) + missing(3 images) + mismatched(flags)`
and `uploads files = referenced + orphaned(339) + cache duplicates(84 audio copies)`.
Every orphan gets a classification (hub/tutorial/essay imagery vs true orphan) rather
than being silently excluded.

## 4. Coverage reconciliation vs V2 (evidence-only comparison)

V2 covered 89/197 listening, 268/317 reading, 12/131 writing, 178/179 speaking, 5/125 GT.
The new pipeline's coverage is reported against the **source**, not V2; V2 is consulted
only as a cross-check where the raw page is ambiguous (and raw source always wins).
No V2 record migrates into the new DB without passing all validation layers.

## 5. Report shape (produced by extraction run S10)

```
per module:
  pages_discovered / pages_parsed / pages_failed
  tests → verified / quarantined(by reason) / duplicate / irrelevant
  groups → verified / quarantined
  questions → verified / quarantined / duplicate
  answers → mapped / unmapped(reason) / empty-source-key-items
  assets → resolved / missing / mismatch-flagged / orphan-classified
invariants:
  discovered == verified + quarantined + duplicates + irrelevant   (must hold exactly)
  Σ counts across modules == global counts                          (must hold exactly)
```

## 6. Acceptance thresholds for the build phase (proposal)

- Page parse success: 1,091/1,091 (static site; any failure is a bug).
- Answer-key sequential integrity: ≥ 99% of keys fully sequential; remainder itemized.
- Question-count agreement (3-way) per test: target ≥ 90% of full tests fully agreeing;
  every disagreement quarantined with evidence, none silent.
- Zero records emitted without provenance (hard invariant, enforced by emitter).
- Zero synthetic strings in emitted content (emitter rejects records lacking rawExcerpt match).

## 7. Reproducibility of the numbers themselves

Reconciliation outputs are generated by the same deterministic run that emits the DB;
a re-run must reproduce the report byte-identically (modulo run timestamps kept outside
the report body). Any drift ⇒ pipeline bug, treated as a build failure.
